## Manual QA Steps

1. `npm ci && npm run validate:production`；运行 `npm run preview`。
2. 桌面依次切换透视、正面、侧面、俯视，旋转查看车尾与轮拱。
3. 拖动 slider 至 0/25/50/75/100，再往返两遍，确认复位。
4. 点选车门并拖动相机；松开不得改变已选部件。
5. 分别选择六个分类，切换分类隔离，检查隐藏部件不可被画面点选。
6. 在目录搜索任意 GEN ID，隔离并 Fit View，尤其检查轮毂螺母和气门嘴。
7. 100% 下切换语言；检查阵列、ID、相机保持。手动旋转不会持续被回正。
8. 在真实手机上测试拖动、双指缩放、滑杆、滚动目录与返回展台。
9. 开启线框/自动旋转，选部件/分类/隔离，再 Reset；所有模型状态应复原。
10. 检查网络请求只指向自身静态资源；模拟 context loss 后点击 Retry。

## 接缝、前脸、尾部与车轮二次修订

用户指出前脸上沿不齐、机盖及尾部缝隙过大、轮胎不真实后，进行了以下修正：

- 机盖与翼子板肩面采用共同参数边界。针对实际装配网格新增 82 点接缝检测：最小 5.0990 mm、最大 5.0991 mm（设计比例），并验证机盖镜像对称。
- 格栅外框改为对称开孔面板，避免 Catmull-Rom 曲线过冲；降低灯组高度，增加凸面投射透镜。
- 补齐翼子板肩面、后侧窗下围和尾窗框，与原部件合为一个物理面板；没有增加占位目录件。
- 尾窗、尾门、尾灯与保险杠使用一致的包角曲率，缩小后部断开感。
- 轮胎从带方块胎纹的圆环改为包含胎唇、侧壁、胎肩和纵向沟槽的轮胎截面；轮辋补内筒，轮辐改为锥形分叉造型。
- 该轮为 346 Mesh / 311,740 triangles。生产构建、346 件独立射线检测、复位、三画幅阵列检查均通过。当前细节是程序化造型，测试不代表真实装配公差或原厂零件精度。

本次生产页面已检查正面、侧面、前后透视并完成复位；未捕获浏览器 error / warn。最新截图为 `refined-seams-exterior.png`、`refined-seams-front.png`、`refined-wheels-side.png`、`refined-seams-rear.png`。
